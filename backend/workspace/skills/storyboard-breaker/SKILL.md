# 分镜拆解手册

## 这一步做什么

把剧本切成一串**分镜段落**，一段 = 一个视频生成任务。切分单位是叙事节拍，同时守住时长预算与台词承载力，产出的序列要有结构、字段齐全。

## 什么是一个分镜段落

一段（segment）就是一个视频任务，规则如下：

- 整段时长 **8-15 秒**，装 **2-4 个子镜头**
- 子镜头之间允许切镜（换景别/角度/对象，硬切衔接）
- 整段锁死在一个场景里，**不许跨场景**（`scene_id` 是段落级绑定）
- 每个子镜头 2-6 秒，只干一件事：一个动作、一个反应或一个特写

## 拆解四步

1. `read_storyboard_context` 拿齐剧本、角色、场景、道具与已有分镜摘要
2. **认节拍**：找剧本里的【开场】【触发】【高潮】【收尾】标记，没有标记就找叙事拐点（换地方、揭开规则、情绪炸点、反转）。**节拍交界处必须断段**；同一节拍的子镜头尽量进同一段；一条完整的因果链（铺垫-发生-反应）不许被切散
3. **算总量**：目标总时长 = 剧本字数 ÷ 500字/分钟；段落数 ≈ 目标总时长 ÷ 12秒，上下可浮动 20%。偏离太多不合格
4. **段内切子镜头**：沿动作、视角、对象的切换点下刀；每段字段全部补齐后 `save_storyboards` 一次性入库

## 时长怎么给

### 按段落性质分档（禁止一刀切）

| 段落性质 | 建议时长 | 常见内容 |
|---|---|---|
| 过渡 | 8-10 秒 | 赶路、空镜、环境交代、转场 |
| 叙事 | 10-15 秒 | 常规推进、对话 |
| 爆点 | 12-15 秒 | 特写、揭规则、情感爆发、反转；子镜头步调放慢，单镜可停 4-6 秒 |

### 台词兜底公式（硬规则）

**段落时长 ≥ description 中台词旁白总字数 ÷ 4.5字/秒 + 2 秒表演余量**

一段装不下的台词挪去下一段，宁可分段不许塞爆。

## 段落十三项字段

1. **镜头标题**：3-5 字说清这段拍的是什么（例"噩梦惊醒"）
2. **时间**：具体时刻 + 光线情况
3. **地点**：场景全称 + 空间格局 + 环境细节
4. **景别**：以段落主导景别为准，混合时写组合（"中景+特写"）
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推/拉/摇/跟/移（段内各子镜头可各异）
7. **画面描述** `description`：以 `【镜头1】…【镜头2】…` 逐子镜头写观众看到与听到的东西——先写画面（谁 + 具体动作 + 肢体细节 + 表情）；子镜头带台词就在其内写「角色名说：「台词」」，画外音写「旁白：内容」
8. **画面结果** `result`：段落收尾那一瞬的后果 + 可见细节
9. **氛围** `atmosphere`：光线 + 色调 + 声音 + 总体气氛
10. **时长** `duration`：8-15 秒，且过得了台词兜底公式
11. **场景关联**：能对上已有场景就必须填 `scene_id`
12. **角色关联**：`character_ids` 填本段牵涉的 0 到多名角色
13. **道具关联**：`prop_ids` 填本段出现的关键道具（0 到多件）

## 绑定纪律

### 场景
- 只从 `read_storyboard_context` 返回的 `scenes` 里挑
- `location + time` 能确定匹配时**必须**回填 `scene_id`
- 严禁编造不存在的场景 ID
- 内容明显属于已有场景时，不要再造新场景描述

### 角色
- `character_ids` 只能取自上下文返回的角色列表
- 一段可以零角色也可以多角色
- 凡在本段露面、被看到、有动作或开口的角色，一个不落全绑上
- 纯空镜、环境段、物件特写传空数组

### 道具
- `prop_ids` 只能取自上下文返回的 `props` 列表
- 道具被使用、交接、特写，或在画面中显眼的，必须绑
- 道具特写段允许零角色，但道具照绑，`character_ids` 留空
- 与剧情无关的背景物、场景陈设不绑；无道具的段传空数组
- 绑定的道具将以白底单品图进入视频参考图队列，用它保证外观跨段一致

## 质量线

- `description` 要给人读得顺：逐子镜头写清所见所闻，台词旁白就地放在对应 `【镜头N】` 里
- `image_prompt` 对准段落第一个子镜头：单帧构图、角色外观、环境、光线都要突出
- `bgm_prompt` / `sound_effect` 允许短语，但光写"紧张""悲伤"这种空词不合格
- 局部返工用 `update_storyboard` 改对应段落
