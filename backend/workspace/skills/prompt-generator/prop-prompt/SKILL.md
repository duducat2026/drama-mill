# 道具单品图提示词（白底 · 产品摄影）

## 这张图是什么

一张 product shot：纯白底上只放道具一件，**其余一切都不许出现**——无陪衬物、无人、无环境、无手持。

三条底线：
1. **比例真实**：道具各部件的相对尺寸关系符合实物，禁夸张、禁变形、禁风格化拉伸
2. **轮廓完整**：物件整体入镜居中、四周留白，任何一处都不允许被画框切断
3. **背景零叙事**：纯白只是衬底，不营造场景感、不给情节暗示、不加装饰元素

## 提示词骨架（单段中文，依序填充）

```
单品产品图，标准产品摄影视角，[道具名 + 材质/颜色/形状/尺寸 + 新旧与磨损细节]，
各部件比例真实，纯白底上单独摆放，居中完整入镜，轮廓无裁切，
背景干净不带任何叙事信息，无陪衬物、无人、无环境，
均匀柔光摄影棚灯，浅淡落影，高细节
```

## 写法要点

- 以道具 `name`（名称）与 `description`（物品外貌）为唯一素材：材质、颜色、形状、大小、新旧程度、磨损痕迹**逐项写全**——这些细节就是道具的辨识度
- 机位用标准产品视角：3/4 微俯（顶面侧面同时可见，立体感最好）；片状物（纸、证件、照片）改正俯平铺
- 主体居中、四周留白，比例真实、轮廓完整
- 光线用均匀影棚柔光，落影要淡，细节拉满
- 只写物体本身，不提剧情、人物、用途——画面与背景都不承载叙事
- 全文纯中文，不掺英文单词；**禁止**"电影质感"字样（道具图是产品图，不是剧照）

## 黑名单

- 入镜任何手、人、陪衬物、环境
- 包装/底座/展架（属于道具本体的一部分才可保留）
- 画面文字、水印、签名（道具身上印刷的字与图案可保留并描述）
- 环境反光、有色光
- 夸张透视、比例失真、轮廓被裁切
