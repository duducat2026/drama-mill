# 场景建立镜头提示词（广角空场 · 无人物）

## 这张图是什么

一张**广角 establishing shot**：没有任何人物的纯环境图，需要让人（以及生成模型）一眼读出整个空间的构造——人从哪里进出、地面墙面是什么质感、核心陈设各自钉在哪个位置。它充当该场景所有镜头的背景母版，因此空间结构必须连续、自洽、可反复复用，机位视角保持平稳通用。

## 提示词骨架（单段中文，依序填充）

```
固定机位广角，清晰的建立镜头，[地点与年代质感]，[时段]，
前景[框景元素]、中景[主体空间]、后景[纵深延伸]三层拉开，
出入口[门或通道的位置样式]，地面[材质与状态]，墙面[材质与颜色]，
[核心陈设及其相互位置]，
空间结构连续自洽，
[光源/色温/明暗关系]，[环境气氛]，
画面里没有任何人物，空场景，电影质感
```

## 空间可读性规则

判断标准：读得懂、对得上、下次还能用。

- 前景：放 1-2 个具体框景/遮挡物（门框、桌角、绿植、设备边角）拉开纵深
- 中景：场景主体空间与核心陈设（产线、床铺、柜台）
- 后景：空间的延伸方向（远墙、窗、走道、天际线）
- 出入口：门/楼梯/通道的**位置与样式必须点名**（如"画面左侧一扇铁门"）——后续镜头调度人物进出全依此图
- 地面、墙面：材质、颜色、新旧状态写具体（"水泥地泛油渍""石灰墙皮剥落"）
- 核心陈设取 2-4 件，交代**相互方位**（"产线贴墙排开、尽头是吧台"），只列名词不合格

`prompt`（场景描述）里的陈设、年代感、标志物都要逐项落进文字；`lighting`（光影）要具体到光源朝向、冷暖、明暗落差（"顶灯冷白，机器底部压出硬影"）。

## 视角与气氛

- 平视或轻微俯视的稳定广角；忌大俯大仰、鱼眼、歪构图——此图要当固定背景反复用
- 用 `location` + `time` 锁定时段光基调（白天/夜/黄昏差别巨大）
- 抽象情绪翻译成可观感：「压抑」→「空气发闷、光线昏低沉」
- 全文纯中文，不掺英文单词

## 黑名单

- 出现任何人物，含背影、剪影、画框/屏幕中的人（须明写"画面里没有任何人物"）
- 可读文字、招牌字、水印、签名
- 运动模糊或移动中的物体（参考图必须绝对静止）
- 只堆陈设清单却不交代相对方位
