# 角色设定参考图提示词（脸部特写 + 全身三视图）

## 这张图是什么

一张 character reference sheet，版式恒定：

- 左半区：头部肩部的正面特写，要求五官、头发、皮肤细节全部可辨，承担脸部一致性锚定
- 右半区：同角色的正面、90° 侧身、背面三个全身像水平并排，等高、头顶与脚底各成一条直线

取舍准则：**一致性优先于好看**。此图是后续一切角色图与视频参考的母版，形象必须中性、干净、可反复复用；不要把它画成一张有艺术发挥的单幅作品。

## 提示词骨架（单段中文，依序填充）

```
角色设定图：左边脸部特写，右边并排正面、侧面、背面三个全身像，同一个角色，
全身入镜，标准 A 字站姿，三个全身像等高、顶脚对齐，
[年龄感/性别感/身材体态]，[长相五官]，[头发]，[衣着与佩件]，
特写与三个全身像的五官、头发、衣着完全相同，
纯白底，均匀柔光，电影质感
```

## 要素落笔次序

把辨识度最高的信息写在最前，`appearance`（样貌）与 `styling`（妆造）里的每个要素都要落到文字上：

1. 身份框架：大致年龄、性别气质、身材（高矮胖瘦与习惯性姿态）
2. 长相：脸型、眼形、以及疤痕/痣/眼镜等标志物——左区特写全靠这段支撑
3. 头发：色、长、造型
4. 衣着：款式、配色、面料、做旧或磨损状态（例："袖口沾着焊锡点的起皱工装"）
5. 佩件：仅保留有辨识价值的，忌堆砌

性格不可直书，需翻译成外表可感的描述——"憔悴"应写成"目光涣散、肩线塌着"。

## 版式与一致性硬约束

- 左区特写：正对镜头、表情中性，头至肩完整不出框
- 右区三全身像：正/侧/背同一人，**等高、等距并排**，顶线与底线水平
- 必须明文写入"特写与三个全身像的脸、头发、衣着完全一致"
- 站姿放松自然，便于后续二创复用
- 影棚式均匀柔光，禁止戏剧化明暗——参考图要能适配任何场景
- 全文纯中文，不掺英文单词

## 黑名单

- 动感姿势、夸张表情、手拿道具、双人同框
- 任何部位被画框切断（全身像脚到头顶必须完整；特写头肩必须完整）
- 画面内文字、标签、水印、签名
- 浓重投影、有色环境光、背景出现任何物件
