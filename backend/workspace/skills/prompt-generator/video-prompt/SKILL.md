# video_prompt 生成（分镜段落 → 视频提示词）

## 任务定义

输入一个分镜段落（`description` 内的【镜头N】子镜头结构与台词/旁白、`atmosphere`、`duration`），产出驱动视频模型的 `video_prompt`。约定：**一个段落对应一条 8-15 秒的视频，段内允许切镜**——段与段之间允许换景别/换角度/换对象并以硬切衔接，但**绝不换场景、绝不闪回**。

## 输出格式

以 3 秒为最小时间单元，每段一行、行间换行分隔；时间轴必须首尾相接，不允许重叠或空洞：

```
0-3秒：@咖啡厅，近景固定机位，@小明垂头盯着手机，指尖一下下敲桌，神色焦躁。
3-6秒：切门口全景，门铃叮响，@小红推门进来，裹进一股冷气。
6-9秒：切回中景，@小红含笑走向小明落座，小明说：「你终于来了。」
```

## description → 时间段的映射律

`description` 是 video_prompt 的唯一内容源（画面、动作、台词、旁白尽在其中）：

- 每个 `【镜头N】` 展开为 **1-2 个连续 3 秒段**：次序照旧，不漏、不并、不凭空加镜头
- 台词/旁白取自对应 `【镜头N】` 内的「角色名说：「…」」「旁白：…」，归入该子镜头映射的段；**严禁新造 description 之外的台词**
- 画面动作一律以 `description` 为准；`atmosphere` 只用来补各段的光线、色调、气氛

## 单段内部结构

每段按此顺序落笔（空项可跳，动作/画面不可跳）：

**时间段 ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作表情 ＋ 对白或旁白 ＋ 光线气氛**

- 首段承担空间交代：场景 + 机位 + 人物站位状态，让人一眼知道在哪、看谁
- 切镜段开头用"切到/切回"承接，随后重新报景别与主体；切镜位置对齐 `description` 的【镜头N】结构
- 每段只处于一种镜头状态（近/中/全/特写；固定/推/拉/摇/跟）；同一子镜头内运镜保持连续，跨切镜才可换
- 一段一个主动作，动词要看得见（走、转身、抬头、攥紧、停顿）
- 情绪只写可见形态：不写"伤心/紧张"，写"垂下头、指节抠着杯沿、呼吸变沉"
- 对白格式「角色名说：「台词」」，旁白格式「旁白：内容」；3 秒读不完的长句拆进多段；无对白段可交代环境音/动作音（"机器轰鸣不断"）

## @ 引用规约

- `@场景名` / `@角色名` / `@道具名`：名字与对应资产列表**逐字一致**，不许缩写、不许附加符号
- 道具仅在画面清晰可见/被使用/给特写时引用
- 生成阶段会把 `@名字` 自动替换为参考图标记（`@小明` → `@图片1小明`），错名即断链
- 每段至少 1 个 @ 引用锚定画面；有角色的段必须 @ 该角色；只准引用本段已绑定的场景/角色/道具

## 时间轴算术

- 段数 = `duration` ÷ 3 秒向上取整；各段时间区间相加 = 段落总时长
- 节奏模板：首段建立空间 → 中段推动作/冲突 → 末段收在结果或情绪点上

## 黑名单

- 跨场景、闪回（一段只在一个场景里发生）
- 引用列表之外的任何场景/角色名
- 心理描写、文学比喻（模型只画得出可见画面）
- 英文混写（视频提示词全中文）

## 落库

调 `update_storyboard` 只写该段的 `video_prompt` 字段：别动其他字段，别重拆整集。
