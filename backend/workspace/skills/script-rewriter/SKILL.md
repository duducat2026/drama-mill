# 剧本改写手册

## 这一步做什么

把小说原文转写为**格式化剧本**：主线不动、画面感加强、靠对白推剧情。它是资产提取与分镜拆解的标准进料。注意：**镜头语言不属于这一步**，一个字都不要写。

## 五条改写原则

1. 主线故事与人物关系原样保留
2. 叙述文字一律翻成看得见的场景描写
3. 情节靠对白往前推，旁白能省则省
4. 单场戏 30-60 秒，按短视频节奏剪裁
5. 景别、机位、运镜全部禁止——那是分镜步骤的事

## 剧本长这样

```
## S01 | 内景 · 巷口面馆 | 午市收尾

午后两点，面馆里没了客人，热气从灶台上一直漫到场子中间。

阿香靠在收银台后面拨算盘，忽然朝门口瞟了一眼。

老陈：（掸了掸衣角）来碗阳春面，多抓一把葱。
阿香：（没抬头）好久没来，还是老坐位？
```

**三条格式约定**

- 场景头固定写法：`## S编号 | 内景/外景 · 地点 | 时间段`
- 动作段落用自然行文，夹带任何镜头术语即违规
- 对白行固定写法：`角色名：（状态/表情）台词内容`

**篇幅基准**：成品比原文多出约两到三成即可——多出来的是场景头与对白格式，不是让你续写剧情。

## 操作顺序

1. `read_episode_script` 取原文
2. 掂量原文构成：对话/叙述/心理各占多少
3. `rewrite_to_screenplay` 做改写
4. 对照上面的格式约定自查一遍
5. `save_script` 落库

## 经验条款

- 心理活动两条出路：变成表情动作，或转成画外音
- 大段叙述切碎成若干短场景
- 每场戏都要有一个情绪拐点
- 角色说话腔调前后统一
- 场景号从 S01 起连续编号，不断号不跳号
- 时间段写实写细（清晨、黄昏、深夜），"白天"这种糊弄词不要用
